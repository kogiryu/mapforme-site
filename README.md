# MapForMe 紹介サイト

[MapForMe](https://kogiryu.github.io/mapforme-site/) — Google マップに保存した「行きたい場所」を、自分のための場所台帳に整理する iPhone アプリの紹介サイトです。

- `index.html` — トップページ
- `guide/` — Google マップからの取り込みガイド
- `assets/illustrations/` — サイト用イラスト（SVG 原本と書き出し PNG）
- `assets/img/features/` — 「できること」のイラスト。配布された PNG は白ベタ背景なので、
  白を抜いた透過版に変換して置いています（差し替える時も同じ処理が要ります）

静的 HTML/CSS のみ。ビルド工程はありません。GitHub Pages で配信しています。
